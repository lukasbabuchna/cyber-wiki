## What this is

A wiki for university students who want to work in security, written so a motivated
high-schooler can follow it. Twelve parts, from the CIA triad to the Cyber Resilience Act.

Every page ends with the sources it was written from. Every offensive technique is shown as
vulnerable code plus a commented exploit, never as a live-target recipe. See
[ADR-0001](https://github.com/lukasbabuchna/cyber-wiki/blob/main/docs/adr/0001-lab-graded-offensive-content.md)
for why.

## Who wrote this

Written with the sources checked on the date shown per page. Versions move: OWASP's web
Top 10 became the 2025 edition, the LLM Top 10 became the 2026 edition, and MITRE ATT&CK
reached v20 in October 2026. Where a version matters, the page says which one it used.
