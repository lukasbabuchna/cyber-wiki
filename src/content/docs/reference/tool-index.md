## Reconnaissance

| Tool | Purpose | Judgement it cannot replace |
| --- | --- | --- |
| `dig`, `whois` | DNS and registration data | Whether the result is in scope |
| crt.sh | Certificate transparency | Which subdomain is interesting |
| `amass`, `subfinder` | Subdomain enumeration | Ownership verification |
| `httpx` | Probing live web services | What "live" means for the engagement |
| Shodan / Censys | Exposed service search | Whether the host is yours to test |

| Tool | Purpose | Judgement it cannot replace |

## The rule

A tool produces observations. A professional produces **decisions**: what matters, what to do, and
what evidence supports it. If your report can be generated by a tool, it will be ignored by a
client and outperformed by anyone who understands the system.
