## How to use the source index

When a page cites a standard, the source index records:

- The exact version.
- The canonical URL.
- Whether it is current or historical.
- What it is good for.

That matters because security standards age: PTES is unmaintained, OSSTMM 3.02 is from 2010,
NIST SP 800-115 has not been revised since 2008, while ATT&CK and the OWASP lists are updated
regularly.

## How to use the checklists

Checklists are not a substitute for judgement. They are a way to avoid forgetting the same six
things under pressure:

```text
Before an engagement
Before a code review
Before declaring an incident contained
Before publishing a finding
Before deleting evidence
```

## A note on completeness

No wiki is complete. This one is organised so that gaps are visible: every part names what it
covers and links to what it does not. If a page is missing, the part index says so rather than
pretending otherwise.
